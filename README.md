# YourHome

YourHome is a WordPress application built as a first-party block theme. Gutenberg React blocks, templates, styling, and public rendering all belong to `wordpress/themes/yourhome/`.

The local stack contains only MySQL and WordPress. WordPress is available directly at `http://localhost:8080` by default.

Local architecture, specifications, tasks, operating notes, and the Memory Bank are organized under `info/` and intentionally ignored by Git.
